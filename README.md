# Яндекс Видео — Скачать

Chrome Manifest V3: кнопки скачивания под карточками поиска Яндекс Видео, в открытом плеере Яндекса и на страницах роликов VK Видео.

## Использование

В выдаче — «↓ Скачать» под карточкой. На странице просмотра Яндекс Видео и VK Видео — панель «↓ Скачать текущее видео» справа внизу. Она использует источник текущего ролика, а не рекомендаций. Панель показывает ход загрузки и кнопку отмены.

Файлы сохраняет локальный помощник в «Загрузки/Яндекс Видео». Нужен отдельно установленный Native Messaging host `ru.local.yandex_video_downloader`; этот репозиторий содержит браузерную часть. Один только этот репозиторий без помощника не скачивает видео.

## Установка и обновление

В `chrome://extensions` включить режим разработчика и загрузить корень этого репозитория как распакованное расширение. При обновлении исходников нажать кнопку обновления на карточке расширения, затем обновить страницы с видео. При добавлении VK Chrome может запросить подтверждение доступа к VK Видео.

Расширение не читает cookies, пароли и историю. Оно запускает помощника по ручному нажатию кнопки. До двух загрузок одновременно, без автоматических повторов. Закрытие вкладки отменяет её загрузки. Закрытые, защищённые и недоступные ролики могут не скачиваться. Наличие кнопки не гарантирует доступность конкретного файла.

## Проверка

`node --test tests/players.test.cjs`

Проверяются источник текущего плеера, изоляция от рекомендаций, допустимые отправители, обновление панели при навигации и существующие карточки. Живое скачивание проверяется отдельно: синтетические тесты не доказывают доступность каждого ролика.
