# Яндекс Видео — Скачать

Chrome Manifest V3: кнопки скачивания под карточками поиска Яндекс Видео, в открытом плеере Яндекса и на страницах роликов VK Видео.

## Использование

В выдаче Яндекса и у карточек «Смотрите также» на VK Видео — «↓ Скачать» под карточкой. Кнопка боковой карточки скачивает именно её ролик без переключения текущего. На странице просмотра Яндекс Видео и VK Видео — панель «↓ Скачать текущее видео» справа внизу. Она использует источник текущего ролика, а не рекомендаций. Панель показывает ход загрузки и кнопку отмены.

Файлы сохраняет локальный помощник в «Загрузки/Яндекс Видео». Нужен локальный Native Messaging host `ru.local.yandex_video_downloader`. Его исходники и установщик находятся в `native/` и `install.command`. Все загрузки выполняются локально.

## Установка и обновление

На macOS с Python 3 сначала запустить `install.command`. Установщик создаст изолированное окружение с yt-dlp из PyPI в `~/Library/Application Support/YandexVideoDownloader` и зарегистрирует помощника только для ID этого расширения.

В `chrome://extensions` включить режим разработчика и загрузить корень этого репозитория как распакованное расширение. При обновлении исходников нажать кнопку обновления на карточке расширения, затем обновить страницы с видео. При добавлении VK Chrome может запросить подтверждение доступа к VK Видео.

Расширение не читает cookies, пароли и историю. Оно запускает помощника по ручному нажатию кнопки. До двух загрузок одновременно, без автоматических повторов. Закрытие вкладки отменяет её загрузки. Закрытые, защищённые и недоступные ролики могут не скачиваться. Наличие кнопки не гарантирует доступность конкретного файла.

## Проверка

`node --test tests/players.test.cjs`

Проверяются источник текущего плеера, изоляция от рекомендаций, допустимые отправители, обновление панели при навигации и существующие карточки. Живое скачивание проверяется отдельно: синтетические тесты не доказывают доступность каждого ролика.

## Окно расширения

Нажмите значок с жёлтым логотипом: окно покажет текущий ролик, кнопку скачивания/отмены и состояние помощника. «Открыть папку с видео» открывает `Загрузки/Яндекс Видео` в Finder. Есть ссылки на видеопоиск, VK, инструкцию и исходники. На выдаче вместо текущего ролика показано число кнопок на странице.

## Удаление

Удалить расширение через Chrome. Затем удалить только его регистрацию `~/Library/Application Support/Google/Chrome/NativeMessagingHosts/ru.local.yandex_video_downloader.json`, если она указывает на `YandexVideoDownloader/native/launch.command`, и каталог `~/Library/Application Support/YandexVideoDownloader`. Скачанные видео остаются в Загрузках.

## Устройство

Content script распознаёт ссылки карточек и текущего плеера. Service worker проверяет отправителя и разрешённую ссылку. Native host повторно проверяет origin и ссылку, запускает yt-dlp отдельным процессом и передаёт статусы. Popup не получает разрешений tabs/history/cookies: он обращается только к content script активной вкладки. Команды помощника `ping` и `open-folder` вызываются только из собственного popup; open-folder использует фиксированную папку без входного пути или shell.
